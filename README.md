# SauceDemo QA Assessment

## Application
SauceDemo - https://www.saucedemo.com/

## Test Account
- Username: standard_user
- Password: secret_sauce

## Automation Details
- Language: Java
- Automation Tool: Selenium WebDriver
- Validation: TestNG
- IDE: Eclipse
- Locator Tool: SelectorHub

## Automated E2E Flow
Login → Select Product → Add to Cart → Checkout → Complete Order → Verify Success

## Setup
1. Install Java JDK.
2. Install Eclipse IDE.
3. Add Selenium WebDriver and TestNG libraries.
4. Open the Java project in Eclipse.
5. Open `SauceDemo.java`.

## Run
1. Run `SauceDemo.java` as a Java Application.
2. The Chrome browser will open.
3. The script will execute the complete E2E flow.
4. TestNG assertions will validate the expected results.

## Validations Covered
- Login page
- Cart count
- Cart page
- Checkout information page
- Checkout overview page
- Order completion

## Notes
This is a simple standalone Selenium script created for the assessment.
It is not a complete production automation framework.
